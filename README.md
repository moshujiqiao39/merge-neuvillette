# 合成那维莱特

一个可以在浏览器里直接玩的合成游戏。圆从小到大依次是枫丹的十位角色，两个相同的圆碰到一起，就会变成下一位，最终合成那维莱特。

在线游玩：https://moshujiqiao39.github.io/merge-neuvillette/

## 本地打开

项目不需要安装依赖。

1. 进入这个文件夹。
2. 双击 `打开游戏.bat`。
3. 浏览器会打开游戏页面。

也可以双击 `index.html`。如果头像没有出来，改用上面的方式，或在这个文件夹里执行：

```bash
python -m http.server 8765
```

然后打开 http://127.0.0.1:8765

## 怎么玩

- 电脑：鼠标移动瞄准，点击游戏区域落下。也可以用左右方向键瞄准，空格落下。
- 手机：按住拖动，松手落下。
- 只有前五位会从上面落下：夏洛蒂、夏沃蕾、艾梅莉埃、希格雯、爱可菲。
- 两个相同角色相碰，合成下一位，并得分。
- 那维莱特是最大的一级，不能再往上合成。
- 圆越过警戒线并停住一段时间，这局结束。

## 合成顺序

| 顺序 | 角色 | 合成得分 |
| --- | --- | --- |
| 1 | 夏洛蒂 | — |
| 2 | 夏沃蕾 | 4 |
| 3 | 艾梅莉埃 | 8 |
| 4 | 希格雯 | 16 |
| 5 | 爱可菲 | 24 |
| 6 | 娜维娅 | 36 |
| 7 | 克洛琳德 | 50 |
| 8 | 莱欧斯利 | 68 |
| 9 | 芙宁娜 | 90 |
| 10 | 那维莱特 | 128 |

落下时不得分，只有合成成功才加分。最高分保存在本机浏览器里。

## 项目文件

```text
index.html        页面
css/style.css     样式
js/game.js        规则和物理
assets/           十张头像
图/               你提供的参考截图
打开游戏.bat      Windows 下一键打开
```

前三级保持原来的大小。希格雯及更大的圆再放大一档，最大的大约是最小的 4.8 倍。头像从 `图` 文件夹前三张图鉴截图裁出，亮度已对齐，界面上不写角色名字。

## 说明

这是粉丝向的同人小游戏，玩法类似合成大西瓜，和米哈游没有官方关系。角色名称和头像归原权利人所有。
